# zodify v0.8.0 candidate

Unreleased. Publish only after local verification and an authorized package upload.

This candidate preserves deterministic `.env` parsing, adds canonical diagnostic
records without changing legacy issues, and introduces strict JSON object parsing
and conservative exact JSON Schema export. Numeric types/default insertion in the
unshipped exporter now raise UnsupportedSchemaError instead of silently losing
semantics. Trusted default references and dictionary-depth behavior are preserved.

The public website continues to document the verified 0.6.0 wheel until the
candidate is actually published and installed examples pass against that release.
Validation evidence belongs in the reviewed PR; no old test counts are release proof.
